## Installation

<Callout>
Don't have Rust? Run `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh` to install it.
</Callout>

<Tabs items={['Cargo', 'Homebrew', 'Make', 'Docker']}>
  <Tab value="Cargo">
    The recommended way to install ekphos:

    ```bash
    cargo install ekphos
    ```

    To update:
    ```bash
    cargo install ekphos
    ```

    To uninstall:
    ```bash
    cargo uninstall ekphos
    ```
  </Tab>

  <Tab value="Homebrew">
    An alternative way to install ekphos:

    ```bash
    brew install ekphos
    ```

    To update:
    ```bash
    brew upgrade ekphos
    ```

    To uninstall:
    ```bash
    brew uninstall ekphos
    ```
  </Tab>

  <Tab value="Make">
    Clone and build from source:

    ```bash
    git clone https://github.com/nostacks/ekphos.git
    cd ekphos
    make
    sudo make install
    ```

    To uninstall:
    ```bash
    sudo make uninstall
    ```
  </Tab>

  <Tab value="Docker">
    Run ekphos in a Docker container with SSH access:

    ```bash
    git clone https://github.com/nostacks/ekphos.git
    cd ekphos
    docker build -t ekphos-ssh .
    docker compose up -d
    ```

    Connect via SSH:
    ```bash
    ssh ekphos@localhost
    ```
  </Tab>
</Tabs>

## First Run

<Steps>
  <Step>
    ### Launch ekphos

    ```bash
    ekphos
    ```

    Or open a specific folder:
    ```bash
    ekphos ~/notes
    ```
  </Step>

  <Step>
    ### Create your first note

    Press `n` in the sidebar to create a new note. Enter a name and press `Enter`.
  </Step>

  <Step>
    ### Start editing

    Press `e` to enter edit mode. New installations use Standard editing, so
    you can type immediately and press `Ctrl+s` to save without leaving the
    editor. Press `Esc` to return to the preview.

    Prefer modal editing? Press `F6` to switch to Vim and save that preference.
  </Step>
</Steps>

## Interface Overview

Ekphos has a three-panel layout:

| Panel | Purpose | Toggle |
|-------|---------|--------|
| **Sidebar** (left) | File tree navigation | `Ctrl+b` |
| **Content** (center) | Markdown preview/edit | - |
| **Outline** (right) | Heading navigation | `Ctrl+o` |

Use `Tab` to switch focus between panels.

To adjust the layout, focus the sidebar or outline and press `<` to shrink it or
`>` to grow it. Changes happen in five-percentage-point steps and persist across
restarts. You can also set independent
`sidebar_width_percent` and `outline_width_percent` values in the
[configuration](/docs/configuration#panel-sizing).

## Essential Keybindings

These are the defaults. Main Normal-view commands can be changed in the
[`[keybindings]` configuration table](/docs/configuration#keybindings).

| Key | Action |
|-----|--------|
| `n` | New note |
| `N` | New folder |
| `t` | Open today's journal |
| `e` | Edit note |
| `d` | Delete |
| `/` | Search notes (sidebar) |
| `Ctrl+k` | Quick open (files & content search) |
| `Ctrl+f` | Find in buffer |
| `Ctrl+g` | Open graph view |
| `Ctrl+y` | Open task view |
| `Ctrl+z` | Toggle zen mode |
| `F6` | Switch between Standard and Vim editing |
| `?` | Help |
| `q` | Quit |

<Callout>
Press `?` in the preview or `F1` while editing to see the full keybindings
reference.
</Callout>

## Configuration

Ekphos stores configuration at `~/.config/ekphos/config.toml`. Notes are stored in `~/Documents/ekphos` by default.

You can also [apply frontmatter templates by folder](/docs/frontmatter#frontmatter-templates)
when creating regular notes.

<Callout type="warn">
After major updates, run `ekphos --reset` to reset configuration if you encounter issues.
</Callout>
