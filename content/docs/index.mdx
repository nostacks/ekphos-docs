**Ekphos** is an open-source, terminal-based markdown research tool inspired by Obsidian. Built with Rust for performance, it provides a fast and intuitive way to manage markdown notes directly from your terminal.

## Features

- **Three-panel layout** - Sidebar, content view, and outline navigation
- **Standard and Vim editing** - Type directly or use full modal editing; switch with `F6`
- **Wiki links** - Obsidian-style `[[note]]` linking with autocomplete
- **Graph view** - Explore fast Local and vault-wide Global note maps (`Ctrl+g`)
- **Task management** - Collect `#task` checkboxes in one filterable list with due dates and priorities (`Ctrl+y`)
- **Projects** - Query frontmatter into live property views with `.base` files
- **Canvas** - Arrange and connect editable cards in JSON Canvas files
- **Syntax highlighting** - 50+ languages supported in code blocks
- **Inline images** - Preview images in compatible terminals
- **LaTeX math** - Render inline and display equations in the content preview
- **Fast search** - Fuzzy file search and full-text content search (`Ctrl+k`)
- **Journal mode** - Open or create today's dated note instantly (`t`)
- **Frontmatter templates** - Add folder-specific metadata to new notes automatically
- **Customizable themes** - TOML-based theming with a live theme selector (`Ctrl+t`)

## Quick Install

Install with Cargo:

```bash
cargo install ekphos
```

Alternatively, you can install Ekphos using Homebrew:

```bash
brew install ekphos
```

## Requirements

- Rust 1.90+ (`rustup update` to upgrade)
- For inline images and graphical equations: iTerm2, Kitty, WezTerm, Ghostty, or a Sixel-compatible terminal
