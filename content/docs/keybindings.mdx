Ekphos uses Vim-style navigation in the preview and offers both Standard and
Vim editing. Press `?` in the preview or `F1` while editing to open the help
dialog. The tables below show the default bindings.

<Callout>
  Main Normal-view commands and the shared editor shortcuts below can be
  remapped, given secondary bindings, or disabled in the [`[keybindings]`
  configuration table](/docs/configuration#keybindings). Other editor Vim
  commands and controls inside dialogs, search inputs, and Graph View remain
  fixed.
</Callout>

### Panel Sizing

Panel resizing works in the preview when the sidebar or outline is focused. Each
keypress changes only that panel by five percentage points, applies live, and is
saved to `config.toml` for the next launch. Widths stop at `5%` and `95%`; the
content panel retains a 20-column minimum on narrow terminals. Below `10%`, a
side panel switches to its minimized five-column view; pressing `>` grows it
back to the full view.

If content is focused, zen mode is active, or the focused side panel is
collapsed, Ekphos leaves the widths unchanged and shows a status message. See
[Configuration](/docs/configuration#panel-sizing) for the corresponding
settings and manual reload behavior.

### Navigation History

Navigate between previously visited notes, similar to browser back/forward:

| Key | Action                   |
| --- | ------------------------ |
| `-` | Go back to previous note |
| `=` | Go forward to next note  |

These history shortcuts are unmodified keys. Terminal-level shortcuts such as
`Ctrl+-` and `Ctrl++` are not captured by Ekphos.

<Callout>
  Navigation history is recorded when you: - Click or press Enter on a note in
  the sidebar - Press `e` to edit a note - Follow a WikiLink - Open a note from
  the graph view
</Callout>

### Move/Relocate Files

Move notes and folders using vim-style cut/paste:

| Key   | Action                          |
| ----- | ------------------------------- |
| `x`   | Cut selected note or folder     |
| `p`   | Paste (move) to current location|
| `Esc` | Cancel cut operation            |

**How to move a file:**

1. Select the note or folder you want to move
2. Press `x` to cut it (the item will appear dimmed/italic)
3. Navigate to the destination folder
4. Press `p` to paste (move the item there)

<Callout>
**Wiki Links Update Automatically**: When you move a note, ekphos automatically updates all wiki links (`[[note]]`) in your vault that reference the moved note. Links with headings (`[[note#section]]`) and aliases (`[[note|alias]]`) are preserved.
</Callout>

**Visual feedback:**
- Cut items appear dimmed and italic in the sidebar
- Status message shows "Cut: filename" when cutting
- Status message shows "Moved: filename" after successful move

**Error handling:**
- Moving to the same location shows "Already in this location"
- If a file with the same name exists at the destination, shows an error
- Moving a folder into itself is prevented

### Sort Modes

Press `s` to cycle through sorting options. The current mode is displayed in the sidebar header (e.g., `Notes (5) [A→Z]`).

| Mode            | Label  | Description             |
| --------------- | ------ | ----------------------- |
| Name A→Z        | `A→Z`  | Alphabetical ascending  |
| Name Z→A        | `Z→A`  | Alphabetical descending |
| Modified Oldest | `Mod↑` | Oldest modified first   |
| Modified Newest | `Mod↓` | Newest modified first   |
| Created Oldest  | `Cre↑` | Oldest created first    |
| Created Newest  | `Cre↓` | Newest created first    |

<Callout>
  Folders are always sorted first, then notes within each folder follow the
  selected sort order.
</Callout>

### Heading Folding

Collapse and expand document sections based on markdown headings (H1-H3) for better navigation:

| Key     | Action                                     |
| ------- | ------------------------------------------ |
| `Space` | Toggle fold on current heading             |
| `za`    | Toggle fold on current heading (vim-style) |
| `zM`    | Fold all headings                          |
| `zR`    | Unfold all headings                        |
| Click   | Toggle fold when clicking on a heading     |

**Fold indicators**:

- `▼` Expanded (children visible)
- `▶` Folded (children hidden)

When a heading is folded, all content until the next heading of equal or higher level is hidden. For example, folding an H2 hides everything until the next H2 or H1.

<Callout>
  Only H1-H3 headings support folding, matching the outline panel. Navigating to
  a folded heading via the outline panel automatically unfolds it.
</Callout>

### Checkbox Items with Links

When a checklist or managed task contains links, you can navigate between the
checkbox and its wikilinks, Markdown links, or images:

```
- [ ] Check [[Project Notes]]
- [ ] #task Review [documentation](https://docs.example.com)
- [ ] See screenshot ![preview](image.png)
```

- `]` / `[` cycles between the checkbox, links, and each inline image in the item
- When the **checkbox is selected** (highlighted), pressing `Space` toggles it
- When a **link is selected**, pressing `Space` opens it (wikilink navigates, URL opens in browser, image opens in viewer)

The currently selected checkbox or text link uses a yellow background. A selected
inline image gets its own highlighted border and **Open ↗** title.

## Editing Modes

New installations use Standard editing. Existing configurations without an
explicit [`editor.mode`](/docs/configuration#editing-modes) keep Vim behavior
for compatibility. Press `F6` in the preview or editor to switch immediately
and save the preference.

### Standard Editing

Standard mode behaves like a conventional text editor: typing inserts text,
arrow keys move the caret, and holding Shift extends the selection.

| Key                                      | Action                                      |
| ---------------------------------------- | ------------------------------------------- |
| Arrow keys                               | Move the caret                              |
| `Shift` + movement                       | Extend the selection                        |
| `Ctrl+←` / `Ctrl+→` or `Alt+←` / `Alt+→` | Move by word                                |
| `Home` / `End`                           | Move to the start or end of the line    |
| `Ctrl+Home` / `Ctrl+End`                 | Move to the start or end of the document    |
| `PgUp` / `PgDn`                          | Move one page                               |
| `Ctrl+a`                                 | Select all                                  |
| `Ctrl+c` / `Ctrl+x` / `Ctrl+v`           | Copy / cut / paste                          |
| `Ctrl+z` / `Ctrl+y`                      | Undo / redo                                 |
| `Ctrl+k`                                 | Cut the selection or current line           |
| `Ctrl+u`                                 | Paste                                       |
| `Ctrl+f` / `Ctrl+w`                      | Find in the note                            |
| `Ctrl+s` / `Ctrl+o`                      | Save and keep editing                       |
| `Esc`                                    | Return to preview; confirm first if unsaved |
| `F1`                                     | Show help                                   |
| `F6`                                     | Switch to Vim editing                       |

Terminal emulators may reserve clipboard shortcuts. Terminal paste events and
the editor's right-click context menu remain available when that happens.

### Shared Editor Shortcuts

These shortcuts work in Standard editing and in Vim Normal, Insert, and Replace
modes:

| Key      | Action                                                    |
| -------- | --------------------------------------------------------- |
| `Ctrl+l` | Make the current line a managed task                     |
| `Tab`    | Toggle an H1-H3 fold; indent on any other line            |

`Ctrl+l` works on plain, bulleted, and checklist lines. It adds the checkbox and
`#task` marker as needed while keeping indentation and the existing `-`, `*`,
or `+` list marker. It leaves existing managed tasks and unsupported Markdown
blocks unchanged. The insertion is one undoable edit.

Folding hides a heading's content without changing the note. A folded heading
shows a non-editable `…` indicator, cursor movement skips its hidden rows, and a
direct jump or search result automatically reveals its row. Nested folds remain
folded when their parent is reopened. Pressing `Enter` at the end of a folded
heading opens it and creates a line after its existing content; pressing it
inside the heading text splits normally. Fold state lasts for the current
editing session.

In Vim Normal mode, `za` also toggles the current heading, `zM` folds every
H1-H3 section, and `zR` unfolds every section.

## Vim Mode - Visual

Ekphos supports three visual selection modes, matching vim's behavior:

### Entering Visual Modes

| Key      | Mode        | Description                                |
| -------- | ----------- | ------------------------------------------ |
| `v`      | **VISUAL**  | Character-wise selection                   |
| `V`      | **V-LINE**  | Line-wise selection (selects entire lines) |
| `Ctrl+v` | **V-BLOCK** | Block/rectangular selection                |

### Visual Mode (Character-wise)

Press `v` to start character-wise selection. The selection extends from the anchor point to the cursor position, spanning across lines if needed.

```
Example: Selecting "world! How are" with v
Hello, [world!
How are] you?
```

### Visual Line Mode

Press `V` to start line-wise selection. Entire lines are selected regardless of cursor column position.

```
Example: Selecting two lines with V
[Hello, world!]
[How are you?]
```

### Visual Block Mode

Press `Ctrl+v` to start block/rectangular selection. Selects a rectangular region defined by the anchor and cursor positions. Each row only highlights the columns within the block boundaries.

```
Example: Selecting a column with Ctrl+v
192.168.[33].0
192.168.[22].0
192.168.[66].0
```

<Callout>
  Visual Block mode is useful for selecting columns of text, such as IP address
  octets, table columns, or aligned data.
</Callout>

## Vim Mode - Replace

Press `R` in normal mode to enter Replace mode. Characters you type overwrite existing text instead of inserting.

| Key           | Action                                       |
| ------------- | -------------------------------------------- |
| Any character | Overwrite character at cursor and move right |
| `Backspace`   | Move cursor left (does not restore original) |
| `Esc`         | Exit to normal mode                          |

<Callout>
  Replace mode is useful for fixing typos or overwriting specific text without
  changing the overall structure. At end of line, new characters are appended.
</Callout>

## Buffer Search

Press `Ctrl+f` to search within the current note (works in both Normal and Edit modes). In Edit mode, you can also use vim-style `/` (forward) or `?` (backward) to start a search.

| Key                              | Action                     |
| -------------------------------- | -------------------------- |
| Type                             | Search text (live results) |
| `↓` / `Tab` / `Enter` / `Ctrl+n` | Jump to next match         |
| `↑` / `Shift+Tab` / `Ctrl+p`     | Jump to previous match     |
| `Ctrl+c`                         | Toggle case sensitivity    |
| `Esc`                            | Close search               |

After closing the search dialog, use `n` and `N` in Edit mode to continue navigating through matches.

**Features**:

- Search dialog appears in top-right corner
- All matches are highlighted in the buffer
- Current match has a distinct highlight color
- Auto-scrolls to first match
- Match counter shows progress (e.g., "3/15")

**Border colors**:

- Blue: Typing (no query yet)
- Green: Matches found
- Red: No matches

## Quick Open

Press `Ctrl+k` to open the quick open dialog. This provides two search modes:

- **Files** - Search notes by title (fuzzy matching)
- **Content** - Search within note contents (full-text search)

### Navigation

| Key                                        | Action                              |
| ------------------------------------------ | ----------------------------------- |
| `←` / `→`                                  | Switch between Files and Content    |
| `↓` / `Tab` / `Ctrl+j` / `Ctrl+n`          | Next result                         |
| `↑` / `Shift+Tab` / `Ctrl+k` / `Ctrl+p`    | Previous result                     |
| `Enter`                                    | Open selected note                  |
| `Esc`                                      | Close dialog                        |
| Type                                       | Filter results                      |

### Files Mode

Searches note titles using fuzzy matching. Results show:
- Note title
- Folder path (if note is in a subdirectory)

### Content Mode

Searches within note contents. Results show:
- Note title with line number (e.g., `:L42`)
- Matched line with query highlighted

Content search runs in the background to keep the UI responsive. A "Searching..." indicator appears while results are loading.

<Callout>
  When selecting a content search result, ekphos navigates to the note and scrolls to the matching line.
</Callout>

## Theme Selector

Press `Ctrl+t` to open the theme selector. Moving the selection previews each theme across the entire interface in real time.

| Key                    | Action                                |
| ---------------------- | ------------------------------------- |
| `↑` / `↓` or `k` / `j` | Move selection (live preview)         |
| `Ctrl+n` / `Ctrl+p`    | Move selection (live preview)         |
| `←` / `→` or `h` / `l` | Switch between outlined and flat      |
| `Enter`                | Apply and save the theme and style    |
| `Esc`                  | Cancel and restore both previous choices |

The list shows official (bundled) themes first, then custom themes from `~/.config/ekphos/themes/`. See [Themes](/docs/themes) for details.
